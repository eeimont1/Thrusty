# Thrusty v1.0.0

A native Windows control panel for using a Thrustmaster T300 RS as an Xbox 360 controller, with local wheel feedback and a Windows XP-inspired interface.

## Downloads

- **Thrusty-1.0.0-Setup.exe** — recommended installer for Windows 10/11 x64.
- **Thrusty-1.0.0-Windows-x64.zip** — portable application; extract the complete folder.
- **Thrusty-1.0.0-Source.zip** — source, documentation, build scripts and pinned dependencies.
- **SHA256SUMS.txt** — hashes of the three release downloads.

## Highlights

Calibrated wheel and pedal mapping, button remapping, Xbox-rumble conversion, 0–100% centering, assisted steering and near-center boost. Live meters, local feedback tests and **Ctrl + Alt + F12** make setup and troubleshooting easier.

Existing 0.x settings are retained. Close Thrusty before upgrading. Driver installation remains a separate step in **Feedback & setup**.

## Before using

Install the Thrustmaster driver and ViGEmBus if needed. The bundled ViGEmBus is its official final 1.22.0 release; upstream is retired. Thrusty's app and installer are unsigned.

Feedback is synthesized from controller vibration and local wheel motion; it does not reconstruct game steering physics or vehicle speed. Actual GeForce NOW rumble delivery depends on the game and client. Start with modest force and verify the return direction.

The build and mathematical tests were verified during preparation. Consult the repository's actual Actions result and hardware acceptance record for Windows/physical validation; the version number is not a compatibility certification.
