Thrusty

T300 RS to Xbox 360 • Windows 10/11 x64 • Version 1.0.0

A small Windows control panel that turns a Thrustmaster wheel into a virtual Xbox 360 controller and converts received gamepad vibration into wheel forces. The visual style is inspired by Windows XP; Windows XP itself is not supported.

Hardware testing is still required. Version 1.0.0 includes the tested software features, but is not a certified or hardware-validated release. A T300 and a GeForce NOW session were not available during development. The app cannot promise that every GeForce NOW client or game will return vibration.

Steering controls in v1.0

Centering strength spans 0–100%; Spring reach sets how far from center the selected strength is reached. Power-steering feel gives progressive loading and controlled return. Near-center boost firms small corrections without raising force at larger angles; try 40% boost while retaining your chosen strength and reach. Boost defaults to zero for existing settings.

Changes take effect after stopping, saving and restarting the bridge. Try centering 20–30% and reach 25% initially. At 100% centering, Thrusty can send full nominal driver force when held at or beyond reach, subject to Thrustmaster driver/firmware limits. It is not full torque at every angle; local centering is zero at the calibrated center. These settings do not track vehicle speed.

1. Install

  1. Run Thrusty-1.0.0-Setup.exe, or extract the portable folder and run Thrusty.exe. Keep ViGEmClient.dll alongside the executable. No Python, npm, .NET or compiler is needed.
  2. Install the official Thrustmaster T300 Windows driver. Follow Thrustmaster's current PC switch/connection instructions for your wheel revision. In the Thrustmaster panel, use separate accelerator and brake axes. Let the wheel finish its startup calibration.
  3. In Thrusty, open Feedback & setup → Install ViGEmBus and follow its installer. This step requires Windows administrator approval. Restart Windows if requested. If a compatible ViGEmBus is already installed, do not reinstall unnecessarily.
  4. Return to Drive and click Refresh. Close the Thrustmaster test panel before enabling feedback; Thrusty needs exclusive wheel access for forces.

Thrusty installs for your Windows user. Its executable and installer are unsigned and Windows may show an unknown-publisher prompt. The bundled third-party bus driver is the original release download; Thrusty does not install it silently or disable Windows protections.

2. Assign and calibrate

  1. Under Buttons & axes, move one control at a time and look at the raw readings. Select the correct steering, accelerator and brake axes. The initial choices are only defaults and may need changing for your pedal set.
  2. Click Save settings. Center the wheel and release both pedals. On Drive, click Calibrate.
  3. Turn to your normal full left and right endpoints, then press and release each pedal fully. Click Finish calibration. Rest/full pedal direction is detected, so normally leave pedal Invert unchecked after calibration.
  4. Verify that steering is near zero at center, throttle is 0 released and 255 pressed, and brake is 0 released and 255 pressed. Wrong input means checking axes and recalibrating, not starting the game yet.
  5. Press the wheel's buttons and read their numbers on Drive, then assign them on Buttons & axes and save. The initial numbered assignments are editable starting points, not guaranteed T300 labels.

Calibration uses the rotation range set in the Thrustmaster driver. For example, a 360-degree range gives full virtual-stick travel across one wheel turn. Thrusty does not change the wheel's firmware rotation setting or add a physical end stop. Recalibrate after changing the rotation range or attached pedals. Only one saved wheel profile is provided.

3. Drive in GeForce NOW

  1. Click Start bridge before launching your streaming game. Only one instance of Thrusty can run.
  2. Use the native GeForce NOW Windows app as your first test. In the game, choose gamepad/Xbox controls and enable controller vibration.
  3. Start driving and tune the game's gamepad steering sensitivity/deadzone. Thrusty's curve of 100 is linear; values over 100 soften steering near the center. Values below 100 make it more sensitive.
  4. Leave Thrusty running. Stop bridge removes its virtual controller; closing the window also stops output.

4. Enable and diagnose wheel feedback

  1. Stop the bridge. Check Enable wheel feedback, leave rumble at 15% and centering at 0%, then save.
  2. Click Test wheel pulse for a one-second direct wheel test. Mount the wheel securely and keep fingers clear while testing.
  3. Start the bridge and click Test Xbox rumble. This sends a one-second XInput vibration request to Thrusty's own virtual controller. The incoming message counter should advance; the wheel should vibrate if forces are enabled.
  4. In a game, look at the message counter and low/high motor meters. If both local tests work but the game sends no messages, troubleshoot the game's vibration setting and the GeForce NOW session. Thrusty cannot manufacture cloud feedback that never reaches Windows.
  5. Optionally try a small centering value, such as 5%. If the wheel pulls away from center, stop immediately and reverse force direction before testing again. This setting reverses both synthesized rumble and centering.

What this feedback means: the two Xbox motor strengths are mixed into 9 Hz and 23 Hz alternating wheel torque. The optional centering is computed from physical wheel position, independent of steering-axis inversion; Power-steering feel additionally uses filtered local wheel motion to trim fast returns. These are approximations; no game steering torque, tire grip, road geometry or understeer data is transmitted by ordinary Xbox rumble.

Built-in limits: feedback is off initially; total requested force is capped at 100% of DirectInput nominal maximum (the wheel driver's own gain also applies). Effects expire after 100 ms unless refreshed. Rumble is dropped after 5 seconds without a fresh notification; this deliberately shortens long unchanged rumble commands. Local centering can remain active while the bridge runs. Device loss, virtual-controller errors, suspend, exit and STOP ALL stop output. Automatic reconnection is deliberately not performed: Refresh and Start are required.

Emergency stop: Ctrl + Alt + F12 stops the bridge globally, or click STOP ALL. If another app owns the shortcut, Thrusty shows a warning. STOP FORCES disables feedback while leaving input available. Driver/hardware behavior still determines how quickly actual torque ceases.

Troubleshooting

ProblemCheck
No wheelOfficial T300 driver, USB/power, correct PC mode. Check Windows Game Controllers, close that panel, then Refresh. The app lists only Thrustmaster devices so it cannot capture its own Xbox controller.
Wheel busy / no forcesClose wheel testers, other remappers and local games. Force output requires exclusive DirectInput access and constant-force support.
ViGEmBus not readyInstall the bundled driver, restart if required, and check Device Manager. Do not disable driver-signature enforcement or Windows security features.
Double input / wrong controllerDisconnect unused gamepads and close other virtual-controller tools. If needed, use the official HidHide setup guide to hide only the physical wheel from other apps while allowing Thrusty.exe. HidHide is optional and not bundled.
Local feedback works, cloud feedback does notEnable in-game vibration, try a supported game, restart the native GFN session after starting Thrusty. A zero received-message count is a transport/game issue, not proof of a broken wheel effect.
DLL loading errorRe-extract the complete x64 package. The supplied DLL uses system libraries only. Do not download substitute DLLs from random DLL sites.
Calibration won't finishCenter and release before starting, use separate pedal axes, sweep both directions and press both pedals fully. Cancel preserves the last calibration.

Settings, logs and removal

Settings and diagnostic log are stored in %LOCALAPPDATA%\Thrusty. Stop Thrusty before editing settings.ini manually. This app has no analytics, accounts, network service or automatic updater. Driver/support buttons open their documented local installers or web pages. Uninstall from Windows Apps; preferences and the separately installed bus driver are retained. Remove ViGEmBus separately only if other controller tools do not need it.
