# Security reports

For a suspected security issue, use GitHub's **Report a vulnerability** option on this repository's Security tab if the maintainer has enabled private reporting. If it is unavailable, open a minimal issue asking for a private reporting channel; do not publish exploit details or personal data in that issue.

This independent project has no guaranteed response time or commercial support. ViGEmBus and ViGEmClient are retired dependencies. Report upstream findings to the appropriate project and avoid installing replacement drivers/DLLs from untrusted sites.

The app contains no credentials, telemetry endpoint, automatic updater or network service. It opens the documented support pages and local installers on explicit user action. Physical force behavior still depends on driver/hardware correctness; see the documented stop controls and hardware tests.
